# 🤖 AI Resume Screening System

An AI-powered recruitment platform that automates resume screening and candidate shortlisting. The system analyzes resumes using Natural Language Processing (NLP), matches candidate skills with job requirements, and ranks applicants based on relevance scores.

---

## 🌟 Overview

The AI Resume Screening System streamlines the recruitment process by automatically parsing resumes, extracting candidate skills, evaluating job-fit scores, and ranking applicants. Recruiters can efficiently manage candidates through a centralized dashboard while reducing manual screening effort.

## 🚀 Installation

### Clone Repository

```bash
git clone https://github.com/Subhashini-Anbalagan/AI-Resume-Screening-System.git
```

### Navigate to Project

```bash
cd AI-Resume-Screening-System
```

### Run Backend

```bash
cd java-backend
mvn spring-boot:run
```

### Run Frontend

```bash
cd react-frontend
npm install
npm start
```
